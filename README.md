# KermoLauncher

Game launcher with a personal game library hosted on **Nextcloud**. The app pulls a game catalog from a public WebDAV share, supports installation, launching, and playtime tracking.

The repo also includes **KermoLauncher Admin Tool** — a utility for publishing games to Nextcloud (folder scanning, `metadata.json` generation, file upload over WebDAV).

## Features

- Game library fetched from a public Nextcloud link (`metadata.json`)
- Game cards with cover art (first image from `screenshots/`), install status, tags and filtering
- Install with SHA-256 verification, resumable downloads (HTTP Range), parallel downloads
- Playtime tracking and last-launched date
- Themes: light, dark, system
- Launcher auto-updates via GitHub Releases
- Admin Tool: scan game folders, edit metadata (descriptions, tags, launch config), generate and upload `metadata.json`

## Requirements

- .NET 8 SDK
- Windows 10/11

## Building

```bash
dotnet build -c Release
```

To produce a self-contained Windows build:

```bash
dotnet publish GameLauncher.UI -c Release -r win-x64 --self-contained
```

## Nextcloud library layout

```
<shared folder>/
├── metadata.json
└── <Game Name>/
    ├── <game-name>-<version>.zip
    └── screenshots/
        ├── 1.jpg
        └── 2.png
```

The game version is parsed from the `.zip` file name (e.g. `shift-at-midnight-1.1.0.zip` → `1.1.0`). If a folder contains more than one zip, the first one in alphabetical order is used — delete the old archive before uploading a new version.

`metadata.json` format (generated by the Admin Tool):

```json
[
  {
    "id": "shift-at-midnight",
    "name": "Shift At Midnight",
    "version": "1.1.0",
    "description": "...",
    "tags": ["adventure", "pixel art"],
    "dependencies": [],
    "screenshotUrls": ["Shift At Midnight/screenshots/1.jpg"],
    "remoteZipUrl": "Shift At Midnight/shift-at-midnight-1.1.0.zip",
    "sizeBytes": 123456789,
    "sha256": "...",
    "launchConfig": {
      "executablePath": "game",
      "workingDirectory": null,
      "launchArgs": null
    }
  }
]
```

## Setup from a share link

1. Use the Admin Tool to upload games to Nextcloud and share the folder as a **public link**.
2. In the launcher: **Settings → Game source (Nextcloud)** — paste the share link and save.
3. Go back to **Library** and click **Refresh**.

## App data

Settings, library and install state are stored in SQLite:
`%LOCALAPPDATA%\KermoLauncher\launcher.db` on Windows (migration from the legacy `GameLauncher` path happens automatically).
